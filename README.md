# DSA & Programming Fundamentals Repository

This repository is a comprehensive resource designed for anyone looking to master Data Structures, Algorithms, and programming fundamentals—from basic concepts to advanced problem-solving skills. It is especially useful for aspiring software engineers preparing for competitive programming and technical interviews.

## 📚 Week-wise Folder Structure

The content is organized into weekly modules covering a progressive learning path:

- **WEEK01** - Basics of Programming - Level 1  
- **WEEK02** - Basics of Programming - Level 2  
- **WEEK03** - Arrays, Time Complexity & Space Complexity  
- **WEEK04** - Searching & Sorting  
- **WEEK05** - Char Arrays & Strings  
- **WEEK06** - Basic Maths & Pointers  
- **WEEK07** - Recursion  
- **WEEK08** - Backtracking & Divide and Conquer  
- **WEEK09** - OOPs Concepts  
- **WEEK10** - Linked Lists  
- **WEEK11** - Stacks  
- **WEEK12** - Queues  
- **WEEK13** - Generic and Binary Tree  
- **WEEK14** - Binary Search Tree  
- **WEEK15** - Heaps  
- **WEEK16** - Map and Tries  
- **WEEK17** - Dynamic Programming - I  
- **WEEK18** - Dynamic Programming - II  
- **WEEK19** - Graph

## 🚀 Features

- **Step-by-Step Learning**: Progress through weekly topics that gradually increase in complexity.
- **Diverse Concepts**: Covers essential programming concepts, data structures, algorithms, and competitive programming challenges.
- **Practice & Solutions**: Each module contains problems and solutions designed to reinforce your understanding and prepare you for coding interviews.

## 🔧 Getting Started

1. **Clone the Repository**
   ```bash
   git clone https://github.com/iamahmarfaraz/DSA.git
   ```
2. **Navigate to a Specific Week**
   ```bash
   cd DSA/WEEK03
   ```
3. **Explore the Topics**: Each folder contains source code, problem statements, and solutions related to the module's theme.
